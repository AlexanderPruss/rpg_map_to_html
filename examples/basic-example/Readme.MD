# Basic example

This shows what a map might look like after a first session of the campaign. Some features you can note -

# Running the example

Run the binary from this directory. It will prompt you if you want to use the last used config; say yes.

## Extra Pages

There are extra pages at the start of the document, **Obituary** and **Plans**.

## Extra Cell Pages

The starting town, Dingsdorf, also gets an extra page, but as a cell page.

## Links

The document shows how to link to pages by using the page's coordinate.

## Empty Columns

Columns have to exist, but don't need content.
