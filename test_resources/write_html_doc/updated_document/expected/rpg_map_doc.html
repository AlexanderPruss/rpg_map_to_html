Documenting a Map Cell

The app detects which non-empty cells don't have a Cell Page and automatically generates missing ones in alphabetical-ish order.

To document the cell, add sections and highlighted sections like below.

Example Section

This is a normal section, good for describing big features. Use h3 headers to add sections.

Example Highlighted Section

This is a highlighted section, good for focusing in on details such as NPCs or treasure. Use h4 headers to add highlighted sections.

Allowed Markdown

Most markdown is allowed, including links to pages. You can link to a page by using its coordinate, e.g. #001.002.

However, no headers are allowed except for h3 and h4 headers for defining sections.

Columns

Every page is split into two columns. Extra space is filled with SVG art.

Need more space?

Add any number of extra pages by writing a Header starting with '# Extra (Title of your extra page)'. Note that these extra pages also need a ##Title, ## Left Column and ## Right Column, just like the pages generated by the app.

Advanced - Customizing the generated document

You can change the styling and templates used for generating the document. See the document package's documentation.
